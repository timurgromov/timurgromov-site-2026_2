Политика конфиденциальности

Эта страница описывает, как обрабатываются контактные данные, которые пользователь оставляет через форму обратной связи на сайте Тимура Громова.

1. Какие данные собираются

Через форму обратной связи могут передаваться номер телефона и комментарий пользователя, если он решил их оставить.

2. Для чего используются данные

Контактные данные используются только для обратной связи по запросу пользователя, обсуждения свадьбы и согласования встречи.

3. Как обрабатываются данные

Данные не публикуются в открытом доступе, не используются для массовых рассылок без отдельного согласия и передаются только в те сервисы, которые нужны для связи с пользователем и ведения заявки.

4. Срок обработки

Данные хранятся только столько, сколько это необходимо для ответа, согласования деталей и ведения коммуникации по обращению.

5. Запрос на удаление

Пользователь может в любой момент запросить прекращение обработки и удаление своих данных, написав по тем контактам, которые указаны на сайте.

Согласие на обработку персональных данных

Отправляя форму обратной связи на сайте, пользователь добровольно соглашается на обработку переданных им персональных данных для обратной связи, обсуждения запроса, записи на встречу и дальнейшей коммуникации по своему обращению.
