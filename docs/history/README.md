# Project Memory

Эта директория - наследуемая память проекта между чатами, агентами и рабочими сессиями.

Она нужна, чтобы новый человек или AI-агент быстро понял:

- зачем были сделаны изменения
- какие решения уже приняты
- что проверено
- какие риски остались
- какие подходы нельзя возвращать без нового теста

## Как читать в новом чате

1. Прочитать `AGENTS.md`.
2. Прочитать этот файл.
3. Открыть `CURRENT_STATE.md`.
4. Открыть последние записи из `worklog/`.
5. Если задача затрагивает UX, маркетинговую воронку, Telegram, deploy или качество - открыть `DECISIONS.md`.

## Роли файлов

`CURRENT_STATE.md` - быстрый handoff текущего состояния проекта.

`DECISIONS.md` - журнал решений, которые нельзя случайно откатить.

`worklog/` - рабочая летопись законченных изменений: намерение, контекст, проверки и результат.

`RETROSPECTIVE_BOOTSTRAP.md` - короткая ретроспектива, как память была добавлена в уже живой проект.

## Когда писать worklog

Писать запись после каждого meaningful change:

- изменение кода, UX, CTA, структуры воронки или документации
- важное расследование
- deploy/release
- изменение правил проекта
- исправление инцидента
- решение, которое будет влиять на будущие правки
