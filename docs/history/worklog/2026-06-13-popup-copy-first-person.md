# 2026-06-13 - Consultation popup copy switched to first person

## Scope

- `src/pages/index.astro`

## Context

В contact popup форма была написана частично от третьего лица: `чтобы Тимур связался с вами` и `Тимур свяжется с вами`. Для личного бренда это звучало менее прямо и менее дружелюбно, чем обращение от первого лица.

## Changes

- В основном тексте popup заменено `чтобы Тимур связался с вами` на `и я свяжусь с вами`.
- В success-state формы заменено `Тимур свяжется с вами` на `Я свяжусь с вами`.
- Быстро проверен source сайта: проблема была точечной в popup-копирайте, а не в брендовых упоминаниях имени `Тимур` по сайту.

## Verification

- `npm run build`
- `npm run verify:contacts`

## Result

Тон popup стал более личным и консистентным с подачей сайта от первого лица, без удаления брендовых упоминаний имени там, где это действительно имя ведущего, а не narration от третьего лица.
