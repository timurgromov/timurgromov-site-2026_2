# 2026-06-14 - Scenario CTA and popup rich preview

## Intent

Убрать странную пустоту в блоке `Получить сценарий свадьбы` и сделать hero popup визуально ближе к новой странице сценария.

## Context

После добавления отдельной страницы `/scenario/` нижний CTA-блок выглядел несбалансированно на desktop: левая колонка заканчивалась кнопками, а правая оставалась высокой. Hero popup показывал только короткий текст и кнопку, поэтому на фоне новой страницы материала выглядел слишком бедно.

## Changes

- CTA-блок сценария уплотнён: уменьшены отступы, правая колонка стала компактнее.
- В левую колонку добавлена короткая выжимка из трёх пунктов и ссылка `Посмотреть страницу сценария`.
- Hero popup расширен на desktop до двухколоночного preview: слева оффер и действия, справа визуальная карточка с hero-изображением страницы сценария.
- В popup добавлена вторичная кнопка `Посмотреть страницу`, основной CTA `Получить сценарий` оставлен ведущим в Telegram-бота.
- На mobile popup переведён на auto-height с max-height, чтобы не появлялась пустая зона снизу.

## Verification

- `npm run build`
- Browser preview:
  - desktop `1280x720`: CTA-блок стал плотнее, popup открывается двухколоночным, горизонтального overflow нет
  - mobile `390x844`: CTA-блок и popup без горизонтального overflow; popup panel занимает высоту контента без пустого нижнего поля

## Result

Блок сценария выглядит заполненнее, а popup теперь продаёт материал как preview страницы, не меняя bot-first механику получения сценария.
