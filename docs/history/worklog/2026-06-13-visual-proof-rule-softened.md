# 2026-06-13 - Visual proof rule softened for small edits

## Scope

- `AGENTS.md`
- `docs/quick-edit-playbook.md`
- `docs/tilda-zero-editing.md`
- `docs/history/DECISIONS.md`

## Context

Жесткая формулировка про обязательный visual proof для субъективных правок получилась слишком тяжелой для ежедневной работы. В этом проекте владелец часто сам быстрее проверяет live, чем агент делает полную визуальную сверку.

## Changes

- убрано правило, будто агент обязан сам визуально проверять каждый субъективный мелкий твик
- зафиксирован базовый режим: `build + deploy-check + live URL владельцу`
- self-check оставлен обязательным только для UX-рискованных зон и по прямой просьбе владельца
- сохранено требование честно разделять `деплой подтвержден` и `визуальный эффект подтвержден`

## Result

Workflow стал быстрее и ближе к реальному режиму работы проекта: мелкие изменения не блокируются лишней QA, но агент все еще не имеет права выдавать непроверенный визуальный эффект за подтвержденный факт.
