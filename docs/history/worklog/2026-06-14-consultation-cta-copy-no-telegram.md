# 2026-06-14 - Consultation CTA copy without Telegram explanation

## Intent

Убрать из блока `Бесплатная консультация` лишнее объяснение про Telegram и сфокусировать оффер на короткой встрече-знакомстве.

## Context

Пользователь отметил, что фраза `можно не идти через Telegram` сбивает смысл блока: консультация должна продавать безопасную встречу и ответ на вопрос, подходит ли ведущий для свадьбы, а не объяснять внутреннюю механику канала связи.

## Changes

- В CTA-тексте удалено упоминание Telegram.
- Текст заменён на спокойный оффер знакомства: если пара уже выбирает ведущего, можно на короткой встрече разобрать формат свадьбы, гостей, площадку и тайминг.
- Карточка `20-30 минут` уточнена до `20–30 минут` и более мягкого текста `Коротко, по делу, без длинной анкеты и продажи`.

## Verification

- `npm run build`
- `git diff --check src/pages/index.astro docs/history/worklog/2026-06-14-consultation-cta-copy-no-telegram.md`

## Result

Блок консультации теперь продаёт встречу как понятный следующий шаг, без конкуренции с Telegram-маршрутом основного tripwire.
