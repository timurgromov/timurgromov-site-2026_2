# 2026-06-15 - Price consultation tab offer strengthened

## Intent

Сделать вкладку `консультация` в блоке `Честно о ценах` более выразительной, используя логику оффера короткой встречи, но без перегрузки layout и без превращения вкладки в отдельную большую CTA-секцию.

## Context

Текущий текст вкладки был смыслово верным, но выглядел как один спокойный справочный абзац. Пользователь попросил сделать этот кусок заметнее и ближе к формулировкам из новых слайдов про короткую встречу, при этом сохранить существующую геометрию блока цен и не ломать верстку.

## Changes

- В `src/site/home-data.ts` plain-text абзац заменен на компактную HTML-структуру:
  - лид `Если вы уже выбираете ведущего...`
  - 3 коротких bullet-пункта
  - финальная строка `30–50 минут, без обязательств, только про вашу свадьбу`
- В `src/pages/index.astro` добавлены scoped-стили только для `rec862336377`:
  - акцент на словах `короткую встречу`
  - аккуратные буллеты в фирменном оранжевом цвете
  - уменьшенные размеры текста на tablet/mobile без перестройки самого Tilda record
- Контактные CTA внизу вкладки не менялись, чтобы не создавать второй competing CTA внутри блока цен.

## Verification

- `npm run build`
- `git diff --check`

## Result

Вкладка `консультация` стала восприниматься как короткий оффер встречи, а не как фоновое пояснение, при этом правка осталась минимальной и не затронула структуру секции цен целиком.
