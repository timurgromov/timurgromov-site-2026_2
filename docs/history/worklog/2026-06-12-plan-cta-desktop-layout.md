- Context
  - В desktop-версии блока `План-сценарий свадебного вечера` слева оставалось слишком много пустого пространства, потому что bullet-описание и inline-форма были собраны в одной правой колонке.

- Changes
  - Левая колонка раздела переведена в полноценный контентный столбец:
    - kicker, заголовок, текст и кнопки;
    - ниже сразу список `01 / 02 / 03`;
    - ниже note про то, что план не заменяет личную встречу.
  - Inline-форма вынесена в отдельную правую колонку `tg-plan-cta__form-column`.
  - Для desktop скорректированы `grid-template-columns`, `gap` и отступы блока, чтобы визуальная масса слева и справа стала сбалансированной.
  - Для tablet/mobile секция по-прежнему схлопывается в один столбец: сначала контент, потом форма.

- Verification
  - `npm run build` — passed.
  - Local headless Chrome на preview:
    - desktop `1440x900`: список действительно расположен под кнопками слева, форма отдельным столбцом справа;
    - mobile `390x844`: стек остался читабельным, форма идет после контента.

- Notes
  - Это именно перевёрстка композиции desktop-блока, без изменения текстов, логики tripwire-формы и без изменения backend-интеграции.
