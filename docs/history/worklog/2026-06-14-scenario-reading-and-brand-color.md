# 2026-06-14 - Scenario reading polish and brand accent alignment

## Intent

Сделать страницу `/scenario/` удобнее для чтения и привести оранжевый акцент к фирменному цвету основного сайта.

## Context

На странице материала использовался отдельный оранжевый `#cf6438`, который визуально расходился с корпоративным акцентом главного сайта. Дополнительно в статье были два читательских UX-риска:

- на mobile drop-cap во вступлении перетягивал внимание на себя;
- на промежуточных ширинах timeblock-секции выглядели слишком тесно из-за узкой левой колонки.

## Changes

- В `src/pages/scenario.astro` основной accent заменён на фирменный `#fa4604` из главного сайта.
- Подправлены связанные soft-оттенки для карточек и фоновых accent-секций.
- Для timeblock-секций расширена desktop meta-колонка.
- Переключение timeblock-раскладки в одну колонку поднято до `1099px`, чтобы tablet/narrow desktop читались спокойнее.
- Основной prose-контейнер немного сужен для более комфортной длины строки.
- На mobile выключен декоративный drop-cap в первом абзаце вступления.

## Verification

- `npm run build`
- Local browser check via `astro preview`:
  - `390x844`: `--accent = #fa4604`, drop-cap disabled, overflow отсутствует
  - `1024x768`: timeblock one-column, overflow отсутствует
  - `1440x900`: timeblock `280px / 724px`, overflow отсутствует

## Result

Страница сохранила структуру и стиль материала, но стала ближе к фирменному цвету сайта и спокойнее для чтения на mobile и промежуточных ширинах.
