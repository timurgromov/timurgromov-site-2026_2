# 2026-06-14 - Required placeholders in tripwire popup

## Scope

- `src/pages/index.astro`

## Context

После упрощения tripwire popup select-поля получили реальные значения по умолчанию: `Жених`, `Летом`, `Москва`. Это могло засорить CRM одинаковыми заявками от людей, которые нажали кнопку, не выбирая ответы.

## Changes

- В select-поля возвращены обязательные disabled-placeholder варианты, но без длинных формулировок:
  - `Кто вы?`
  - `Когда свадьба?`
  - `Где свадьба?`
- Видимые подписи над select скрыты визуально, чтобы не дублировать текст и не перегружать popup.
- Остальные варианты сохранены: `Жених`, `Невеста`, `Родители`, `Подрядчики`; сезоны/следующий год/пока не знаем; `Москва`, `Московская область`, `Другой город`.

## Verification

- `npm run build`
- `npm run verify:contacts` - passed on `1911x1064`, `1440x900`, `390x844`
- cleanup-check for headless/preview processes - no test processes found

## Result

Popup снова требует осознанного выбора в трех полях, но без прежнего визуального перегруза и длинных обрезающихся placeholder-текстов.
