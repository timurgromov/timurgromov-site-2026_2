# 2026-06-15 - Price consultation copy made more direct

## Intent

Сделать формулировку во вкладке `консультация` логичнее и прямее, чтобы смысл встречи читался сразу, без ощущения разрыва между лидом и списком.

## Context

После предыдущего усиления оффера вкладка стала заметнее, но пользователь увидел, что текст воспринимается чуть рвано: сначала короткий lead, потом отдельный список. Более естественно звучит одна связная фраза про короткую встречу и то, что именно на ней станет понятно.

## Changes

- В `src/site/home-data.ts` `priceConsultationMarkup` переписан в более прямую формулировку:
  - `Если вы уже выбираете ведущего, предлагаю короткую встречу...`
  - в том же предложении перечислены формат свадьбы, состав гостей, площадка, логистика, тайминг и вопрос, подходит ли ведущий
- Нижняя строка `30–50 минут, без обязательств, только про вашу свадьбу.` сохранена без изменений.

## Verification

- `npm run build`
- `npm run verify:pages -- --contains "Если вы уже выбираете ведущего, предлагаю короткую встречу" --contains "30–50 минут, без обязательств, только про вашу свадьбу."`

## Result

Вкладка `консультация` теперь звучит как одна логичная мысль, а не как заголовок с отдельным списком под ним.
