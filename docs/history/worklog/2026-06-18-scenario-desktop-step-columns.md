# 2026-06-18 - Fix desktop step columns on /scenario/

## Context

На странице `/scenario/` блок `Карта свадебного вечера` раскладывал шаги попарно по строкам: `01/02`, `03/04`, `05/06`, `07/08`. По задаче нужно было вернуть desktop-раскладку двумя вертикальными колонками: слева `01..04`, справа `05..08`, без изменения самих пунктов и их общего порядка.

## Root Cause

В `src/pages/scenario.astro` список строился через `eveningStepRows`, который заранее разбивал массив шагов на пары для построчного рендера. Из-за этого desktop-сетка физически не могла заполниться по колонкам.

## Change

- Убран промежуточный `eveningStepRows`.
- `scenario-step-grid` теперь рендерит шаги напрямую в DOM-порядке `01..08`.
- Desktop CSS переведен на grid с заполнением по колонкам: первая колонка получает `01..04`, вторая `05..08`.
- Mobile fallback сохранен одноколоночным и продолжает идти в естественном порядке сверху вниз.

## Verification

- `npm run build`
