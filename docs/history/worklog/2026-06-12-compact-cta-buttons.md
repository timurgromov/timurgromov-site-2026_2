# 2026-06-12 - Compact CTA buttons across custom sections and popups

## Context

После добавления новых CTA-блоков и popup-кнопок кастомные кнопки стали выглядеть крупнее и тяжелее, чем исходный язык интерфейса сайта. Задача - уменьшить их по высоте и внутренним отступам, чтобы вернуть более аккуратный Tilda-like ритм и освободить место в блоках.

## Changes

- Уменьшены `min-height`, `padding`, `font-size` и `border-radius` у кнопок в блоке `План-сценарий свадебного вечера`.
- Аналогично уменьшены кнопки в CTA-блоке консультации.
- Уменьшены кнопки-ссылки и submit-кнопки внутри contact popup и tripwire popup.
- Поджаты success-кнопки после отправки форм, чтобы они не выбивались по масштабу относительно основного UI.

## Verification

- `npm run build`
- `npm run verify:contacts`

## Result

Кастомные CTA-кнопки стали компактнее на desktop и mobile, лучше совпадают по визуальному весу с остальными кнопками сайта и занимают меньше вертикального пространства в popup и новых секциях.
