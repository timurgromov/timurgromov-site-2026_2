# 2026-06-14 - Tighten scenario CTA copy

## Scope

- `src/pages/index.astro`

## Context

На hero и в CTA-блоке про сценарий формулировка была мягче и длиннее: `получить сценарий` и `План-сценарий свадебного вечера`. Пользователь решил усилить оффер более прямой и быстрой формулировкой `сценарий свадьбы`.

## Changes

- В hero CTA текст изменён с `получить сценарий` на `получить сценарий свадьбы`.
- В основном CTA-блоке заголовок изменён с `План-сценарий свадебного вечера` на `Сценарий свадьбы`.
- В основной кнопке CTA-блока текст изменён с `Получить сценарий` на `Получить сценарий свадьбы`.

## Verification

- `npm run build`
- `npm run verify:contacts`
- live-check production after push

## Result

Оффер стал короче и прямее: вместо объясняющей конструкции про план-сценарий пользователь сразу видит обещание `сценарий свадьбы`.
