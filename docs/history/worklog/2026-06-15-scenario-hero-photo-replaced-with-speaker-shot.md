# 2026-06-15 - Scenario hero photo replaced with speaker shot

## Intent

Заменить hero-фотографию статьи `/scenario/` на новый выбранный пользователем кадр, где Тимур крупно считывается как ведущий и лучше подходит для чёрно-белого экспертного первого экрана.

## Context

Пользователь отдельно указал, что ранее поставленный outdoor-кадр не соответствует ожидаемому визуальному ощущению hero и попросил выбрать новый вариант из конкретной подборки. По этой подборке лучшим рабочим вариантом для article hero был выбран горизонтальный кадр `+bF8v_DpbQY8.jpg`: Тимур крупно виден, свадебный контекст понятен, а композиция подходит под текст слева.

## Changes

- В проект добавлен новый исходник hero:
  - `public/images/scenario-hero-host-bw-source.jpg`
- В `src/pages/scenario.astro` hero-фон `/scenario/` переключён на этот файл.
- Для desktop и mobile скорректирован `background-position`, чтобы лицо и микрофон не конфликтовали с левым текстовым блоком.
- Чёрно-белая стилизация оставлена на уровне CSS `filter`, без отдельной растровой подготовки, чтобы сохранить быстрый и обратимый visual pass.

## Verification

- `npm run build`
- live HTML/CSS marker-check after deploy

## Result

Hero статьи `/scenario/` теперь использует новый выбранный кадр с крупным образом ведущего, который лучше работает как экспертный first-screen для статьи.
