# 2026-06-17 — homepage CTA axis and spacing pass

## Что изменено

- Привел оба кастомных CTA на главной (`tg-plan-cta`, `tg-consultation-cta`) к реальной оси соседних Tilda-блоков, а не к отдельному самодельному wrapper:
  - desktop gutter `49px`
  - tablet gutter `40px`
  - mobile gutter `25px`
- Убрал искусственное мобильное заужение `content max-width: 300px`, из-за которого оба CTA визуально сидели глубже, чем остальной сайт.
- Сохранил существующий дизайн, split-button pattern и общую композицию; правка затронула только контейнерную геометрию.

## Почему

На главной одновременно работали две разные контейнерные системы:

- кастомные CTA с собственным centered wrapper и завышенными боковыми gutter;
- native Tilda-блоки с более узкой реальной осью сайта.

Из-за этого оба новодельных CTA начинались правее соседних секций, а на мобильном ещё и сужались сильнее нативных блоков.

## Проверка

- `npm run build`
- Codex in-app browser:
  - `desktop 1440x900`: оба CTA стартуют с `left: 49px`
  - `mobile 390x844`: оба CTA стартуют с `left: 25px`, ширина секции `340px`

## Риск / что смотреть на live

- На live смотреть только общий вертикальный ритм соседних переходов; горизонтальная ось двух CTA теперь унифицирована с остальной главной.
