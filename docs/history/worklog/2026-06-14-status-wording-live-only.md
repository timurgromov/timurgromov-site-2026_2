# 2026-06-14 - Make site-task status wording live-only

## Scope

- `AGENTS.md`
- `docs/history/DECISIONS.md`

## Context

Даже при наличии commit/push/deploy пользователь несколько раз воспринимал статус как ложный, потому что ответы агента формулировались слишком общо: `исправил`, `сделано`, `готово`. Для живого сайта этого недостаточно; нужно отдельно маркировать локальное состояние, git-состояние и live-state.

## Changes

- В `AGENTS.md` добавлено прямое правило: по site-task агент обязан отдельно указывать `локально изменено`, `commit`, `push`, `production/live-check`.
- В `AGENTS.md` закреплено, что слова `сделано`, `готово`, `исправил` допустимы только после live-подтверждения production.
- В `DECISIONS.md` добавлено отдельное process-решение про обязательное разделение статусов.

## Verification

- Documentation-only change.

## Result

Проект теперь фиксирует не только требование деплоя, но и требование точной терминологии статуса. Это должно убрать повторяющуюся путаницу между локальной правкой, push и реально подтвержденным live-результатом.
