# Local Docker Preview

Локальный просмотр сайта можно держать постоянно через Docker Compose, без ручного `npm run preview`.
В этом проекте контейнер специально запускает `build + preview`, а не `astro dev`: так стабильнее для текущего Tilda/Astro шаблона.

## Команды

Запуск:

```bash
docker compose up -d --build
```

Остановка:

```bash
docker compose down
```

Логи:

```bash
docker compose logs -f site
```

## URL

После запуска сайт доступен на:

`http://127.0.0.1:4323/`

Это и есть постоянный локальный адрес для этого проекта.
Порты вроде `4325`, `4326` и другие появляются только у разовых ручных запусков `npm run preview` и не должны использоваться как основной локальный вход.

## Зачем это нужно

- ссылка не зависит от случайно закрытого `npm run preview`;
- контейнер перезапускается сам (`restart: unless-stopped`);
- контейнер держит стабильный локальный preview на одном порту;
- локальная разработка и проверка идут на одном фиксированном порту.

## Важно

После правок в коде нужно перезапустить контейнер, чтобы он пересобрал сайт:

```bash
docker compose up -d --build
```

Для повседневной работы лучше использовать только Docker-команды проекта:

```bash
npm run docker:up
npm run docker:logs
npm run docker:down
```
