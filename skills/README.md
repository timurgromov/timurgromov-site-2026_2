# Project Skills

Reusable skills copied from the local `Tamplates` catalog for this Astro/Tilda
GitHub Pages site.

Use these selectively. Read only the skills relevant to the current task.

## Included

| Skill | Use for this project |
| --- | --- |
| `artifact-cleanup` | Keep screenshots, dumps, local videos, `.env`, and temporary files out of commits. |
| `ci-git-hygiene` | Fix GitHub Actions, branch/push issues, build failures, and clean release commits. |
| `docs-sync` | Keep docs aligned after changes to code, deploy, media hosting, or workflow. |
| `github-private-launch` | Handle GitHub visibility, repo setup, and Pages recovery after private/public changes. |
| `marketing-launch` | Prepare Direct/ads launch notes, offer, CTA, UTM, and landing-page metrics. |
| `platform-deploy` | Work with GitHub Pages and other managed/static deploy targets. |
| `product-design-ux` | Plan meaningful landing-page or funnel UX changes before editing UI. |
| `project-memory` | Maintain durable handoff/memory for important site decisions and incidents. |
| `provider-integration` | Work with VPS media host, external storage, GitHub, analytics, or provider URLs. |
| `security-sanity` | Check secrets, public exposure, admin/provider risks, and launch safety. |
| `smart-vps-deploy` | Work on repeatable VPS/media deploy and production verification flows. |
| `web-ui-verify` | Verify visual/frontend changes in desktop/mobile browser contexts. |
